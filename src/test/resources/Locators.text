# ---------------------------------------------------------------------------
# Centralized selector store for the framework.
#
# This file is the single source of truth for every locator. Page objects read
# these values through the typed accessors in
#   com.satviklabs.locators.Locators
# so no page object ever hard-codes a raw CSS string.
#
# Naming convention:
#   <PAGE>.<ELEMENT>=<selector>
# Grouped per screen, e.g. LOGIN.USERNAME_FIELD, CUSTOMERS.SEARCH_BOX.
#
# Edit a selector here and every page object picks up the change - no page
# object source needs editing.
#
# Note: this file is plain "KEY=value" text. It is named Locators.text and is
# copied to the test classpath by the <testResources> section of pom.xml.
# ---------------------------------------------------------------------------
